# LA Referencia Indexing Filters Library

Field occurrence filtering library for controlling metadata field indexing.

## 🎯 Functionality

Provides configurable filters to limit field occurrence indexing based on rules, reducing index size and improving search relevance by indexing only the top N occurrences of specified fields.
